# 逆算トレログ

目標から逆算して、毎回の重量と回数を決める筋トレ記録アプリです。

**デモ:** https://onoyanma.github.io/gyakusan-trelog/

## 開発の背景

筋トレの目標達成に向けて、自分の Push / Pull / Legs 分割専用の記録アプリを作ったのが始まりです。
記録をつけるだけでは「次に何kgで何回やればよいか」「今のペースで目標に間に合うか」が分からないという課題があったため、
記録から次回の重量を提案し、目標の期限から必要なペースを逆算する機能を加えました。
さらに、自分以外の人も使えるように、分割法や種目を自由に組める形に作り直しています。

## 主な機能

### メニュー
- テンプレート（全身法 / 上半身・下半身 / Push・Pull・Legs / 自分で組む）から開始
- 日の追加・名前変更・並べ替え、種目の追加・削除・並べ替え
- 種目ごとに目標のセット数、回数の幅（下限〜上限）、増量幅を設定
- 約45種目の一覧から部位別に追加。一覧にない種目も自重・単関節を指定して登録可能

### 記録
- 前回の記録を各種目に表示し、前回の値をワンタップで入力
- 次回の重量提案（全セットで回数の上限に届いたら増量、届かなければ同重量で+1回）
- セット数の増減、日付の変更、入力途中の内容の自動保存
- 保存時に自己ベストの更新を自動で検出

### 目標
- 「種目・目標の推定1RM・期限」を立てると、期限までに必要な伸び（kg/週）を逆算
- 2週間以上の記録から実際の伸びのペースを計算し、「順調 / ペース不足 / 達成」を判定
- 計画ラインと実績をグラフで比較、種目別の推定1RMの推移も表示

### データ
- データはブラウザ内（localStorage）に保存。サーバーへの送信はなし
- バックアップ文字列のコピーと、貼り付け・ファイルからの復元

## 工夫した点

- **逆算の可視化**：目標と期限から「週あたりに必要な伸び」を出し、実際のペース（最小二乗法による傾き）と比べて、いま何を変えるべきかを判断できるようにしました
- **次回の重量提案**：ダブルプログレッション（回数の上限に届いたら重量を上げる方法）を採用し、毎回の重量決めに迷わないようにしました
- **推定1RM**：高重量の1回挙げに挑まなくても伸びを追えるよう、Epley式（重量 ×（1 + 回数 ÷ 30））で記録から推定しています
- **誰でも使える設計**：自分専用だった固定メニューをやめ、テンプレートと自由な編集で、分割法や経験に関係なく使える形にしました
- **スマートフォンでの片手操作**：ジムで使う前提で、1列のレイアウト、大きな数字入力、画面下のナビゲーションにしています

## 技術

- HTML / CSS / JavaScript（外部ライブラリなし、1ファイル構成）
- localStorage によるデータ保存
- SVG によるグラフ描画
- ライト / ダークモード対応
